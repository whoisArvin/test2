# Berjis Imaging Center

پیش‌نمایش استاتیک و قابل انتشار وب‌سایت مرکز تصویربرداری پزشکی برجیس.

## اجرای محلی

```bash
python3 -m http.server 4173
```

سپس آدرس `http://localhost:4173` را باز کنید. برنامه بدون build step و وابستگی خارجی اجرا می‌شود.

## تغییرات سریع

- اطلاعات برند، تلفن، آدرس، ساعات کاری، خدمات و محتوای راهنما در ابتدای `app.js` داخل `CONFIG` قرار دارد.
- رنگ‌ها و فاصله‌ها در متغیرهای ابتدای `styles.css` قابل تغییر است.
- لوگو در این پیش‌نمایش با نشان متنی «ب» ساخته شده است؛ برای جایگزینی، تابع `logo()` در `app.js` را با فایل SVG برند هماهنگ کنید.
- فرم نوبت‌دهی فعلاً در حالت نمایشی است و فقط اعتبارسنجی مرورگر را انجام می‌دهد. برای انتشار، تابع ارسال را به endpoint امن سمت سرور متصل کنید.
- تصویر اصلی در `assets/berjis-center.webp` قرار دارد و قابل تعویض است.
- لایه بصری «امضای برجیس» در صفحه اصلی با مدارهای خدمات، کارت‌های شناور و خط اسکن ساخته شده و بدون وابستگی به کتابخانه انیمیشن کار می‌کند.

## مسیرها

`#/`، `#/about`، `#/services`، `#/prep`، `#/articles`، `#/contact`، `#/appointment` و صفحات جزئیات خدمت مثل `#/service/mammography`.
